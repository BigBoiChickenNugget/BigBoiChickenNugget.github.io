A few builds that best represent how I like to work: low-level, hands-on, and systems-oriented.

VisionNode

ESP32-CAM, STM32, Edge Impulse, TensorFlow Lite, MbedOS

A real-time facial recognition system that split image capture and control responsibilities across two embedded devices.

  • Used an ESP32-CAM for imaging and an STM32 for control and display logic.
  • Trained and deployed lightweight machine learning models with Edge Impulse and TensorFlow Lite.
  • Integrated I2C and UART communication between the camera module and controller.

Self-Balancing Robot

ESP32, MPU6050, Fusion 360, PID Control

A two-wheel self-balancing robot that brought together embedded programming, CAD, fabrication, and control tuning.

  • Designed and 3D printed the chassis in Fusion 360.
  • Implemented a PID control loop using MPU6050 IMU feedback for stabilization.
  • Tuned controller gains through test runs and UART logging to achieve sub-5 degree error.

Digital Counter Display

JK Flip-Flops, 7-Segment Displays, Multisim

A sequential logic build focused on timing behavior, stable transitions, and getting the fundamentals right.

  • Designed a circuit using JK flip-flops and multiplexers to iterate through a student ID.
  • Wired and debugged the timing logic to keep the 7-segment display consistent and readable.
  • Strengthened the digital logic habits that still matter in more complex embedded systems work.
